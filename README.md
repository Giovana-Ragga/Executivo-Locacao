# Painel Executivo de Locação — Grupo Ragga

Painel HTML single-file com o controle dos contratos de locação (expansões), degraus de aluguel, cláusulas de reajuste, projeção de AMM e calculadora de multa rescisória.

## Como visualizar

- Abra `index.html` (ou `dashboard_contratos_locacao.html`, mesmo conteúdo) diretamente no navegador.
- Ou ative o GitHub Pages deste repositório (Settings → Pages → Branch: `main` → pasta `/`) para ter uma URL pública sempre atualizada, ex.: `https://giovana-ragga.github.io/Executivo-Locacao/`.

## Atualizações

Este arquivo é atualizado a cada rodada de revisão dos contratos. Basta substituir `index.html` e `dashboard_contratos_locacao.html` pela versão mais recente e enviar (commit) as alterações.
